🛠️ Setting up LookAhead Steering Controller Richard Burns Rally (RBR)

  1. Download & Extract: Download the latest LookAhead Steering Controller (RBR Build) archive from the main hub and extract it to your preferred folder.
  2. Enable TrackIR in RBR Config: Open RichardBurnsRally.ini located in your main RBR installation directory using Notepad. Locate or add the line UseTrackIR = true and save the file.
  3. Set 1800° Lock-to-Lock Scale: In LookAhead Steering Controller, set Wheel Degrees (Lock-to-Lock) to 1800°. This provides the maximum dynamic scale (5 full wheel turns) with perfect integer sub-multiples (1800 ÷ 2 = 900°, 1800 ÷ 3.33 = 540°, 1800 ÷ 5 = 360°, 1800 ÷ 10 = 180°) that guarantee 100% linear telemetry calculations across all vehicles without rounding errors.
  4. Wheelbase Software Setup: Keep 1800° fixed inside the LookAhead Controller software and adjust the real physical steering lock degrees exclusively within your wheelbase driver software (e.g., Fanatec Control Center / Fanalab, Simucube True Drive, Thrustmaster Control Panel, etc.) to match the real-world rally car specs.
  5. OpenTrack Universal Output Mapping: Open OpenTrack, set the Input protocol to UDP over network (Port 4242) and Output to freetrack 2.0 Enhanced.

📐 Setting up Pro-Sim FOV Utility

  1. Measure Your Setup: Measure your screen size (diagonal in inches), viewing distance from eye level to screen (cm), and monitor bezel thickness.
  2. Input Data: Enter these values into Pro-Sim FOV Utility to calculate your exact mathematical field of view.
  3. Apply Config: Copy the calculated horizontal or vertical FOV directly into your simulator's graphics/camera settings.

❓ Frequently Asked Questions (FAQ)

Why is `UseTrackIR = true` required in RichardBurnsRally.ini?
RBR requires TrackIR integration enabled natively in its initialization file so OpenTrack can inject high-frequency camera position packets directly into the game engine via freetrack 2.0.
Why set 1800° in LookAhead and change degrees only in the wheelbase software?
Setting 1800° as a fixed maximum value inside the LookAhead Controller utilizes the full dynamic range of the software (covering up to 5 full wheel rotations). The 60Hz UDP telemetry remains 100% linear and flicker-free, while your wheelbase software (Fanatec Fanalab, Simucube, etc.) controls the realistic physical steering lock for each specific car.
Do I need separate OpenTrack profiles for LHD (Left-Hand Drive) and RHD (Right-Hand Drive) cars?
No! By setting Source: Roll on both Pitch and Roll axes in OpenTrack, the camera motion remains perfectly symmetrical regardless of driver seating position.
Why use Accela + Hamilton Filter with 1.5° Smoothing and 0.03° Deadzone?
The Accela + Hamilton filter with a 1.5° rotation smoothing and a 0.03° deadzone provides ultra-smooth head movements without adding input latency, perfectly filtering out minor micro-oscillations during high-speed countersteering or drifting.
How does this configuration handle Drifting and Countersteering?
Because the cross-blended Roll telemetry is processed at 60Hz with full 1800° resolution, the camera smooths out high-angle transitions and fast countersteering without camera snapping or losing sight of the apex.
Does LookAhead cause input lag?
The utility operates via high-frequency UDP packets at 60Hz. If you notice any camera delay, simply lower the Smoothing Filter setting to below 10%.

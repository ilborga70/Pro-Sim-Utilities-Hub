🛠️ Setting up LookAhead Steering Controller Richard Burns Rally (RBR)

  1. Download & Extract: Download the latest LookAhead Steering Controller (RBR Build) archive from the main hub and extract it to your preferred folder. Run LookAhead Steering Controller.exe as Administrator.
  2. Enable TrackIR in RBR Config: Open RichardBurnsRally.ini located in your main RBR installation directory using Notepad. Locate or add the line UseTrackIR = true and save the file.
  3. Set Steering Degrees in LookAhead: Enter the exact steering lock value (degrees of rotation) required by the car in-game into the LookAhead Steering Controller.
  4. Match Physical Wheelbase Settings: Set the exact same degree value directly in your physical wheelbase software (e.g., Fanatec Fanalab, Simucube True Drive, Thrustmaster Control Panel, Moza Pit House). Ensure the degrees set in LookAhead, in-game, and in your wheelbase software match 100%.
  5. OpenTrack Universal Output Mapping: Open OpenTrack, set the Input protocol to UDP over network (Port 4242) and Output to freetrack 2.0 Enhanced.

📐 Setting up Pro-Sim FOV Utility

  1. Measure Your Setup: Measure your screen size (diagonal in inches), viewing distance from eye level to screen (cm), and monitor bezel thickness.
  2. Input Data: Enter these values into Pro-Sim FOV Utility to calculate your exact mathematical field of view.
  3. Apply Config: Copy the calculated horizontal or vertical FOV directly into your simulator's graphics/camera settings.

❓ Frequently Asked Questions (FAQ)

Why is `UseTrackIR = true` required in RichardBurnsRally.ini?
RBR requires TrackIR integration enabled natively in its initialization file so OpenTrack can inject high-frequency camera position packets directly into the game engine via freetrack 2.0.
Why must steering degrees match across LookAhead, in-game car setup, and wheelbase software?
Matching the exact real-world steering degrees across all three layers ensures 1:1 dynamic calibration. This allows the 60Hz UDP telemetry bridge to calculate perfectly linear, accurate camera movement without scaling mismatches or dynamic deadzones.
Do I need separate OpenTrack profiles for LHD (Left-Hand Drive) and RHD (Right-Hand Drive) cars?
No! By setting Source: Roll on both Pitch and Roll axes in OpenTrack, the camera motion remains perfectly symmetrical regardless of driver seating position.
How does this configuration handle Drifting and Countersteering?
Because the 60Hz telemetry uses real-time 1:1 steering angle ratio matching your wheel, head movement remains smooth and natural during sharp transitions, high-angle drifting, and rapid countersteering.
Does LookAhead cause input lag?
The utility operates via high-frequency UDP packets at 60Hz. If you notice any camera delay, simply lower the Smoothing Filter setting to below 10%.
